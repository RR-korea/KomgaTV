# T4 보고서: 리더 (feature:reader)

작업: Antigravity — 2026-10-31

## 1. 바꾼 것

### feature:reader (담당 범위)
- **`ReaderViewModel.kt`**:
  - `BookRepository`, `SeriesRepository`, `ServerSessionManager`를 주입받아 책 조회 후 시리즈 메타데이터(`SeriesMetadata.readingDirection`)를 조회하도록 구현.
  - **이어 읽기**: 진입 시 서버에 기록된 진행도(`book.readProgress.page`)에서 시작.
  - **읽기 방향 반전**: 시리즈의 `readingDirection`이 `RIGHT_TO_LEFT`인 경우 D-pad 좌/우 이동 방향을 반전(`onDpadLeft()`, `onDpadRight()`).
  - **프리로드(±2)**: 현재 페이지 기준 `[currentPage - 2 .. currentPage + 2]` 범위(1..totalPages) 내 유효한 페이지들의 절대 URL 목록(`preloadUrls`)을 계산하여 UI 상태에 노출.
  - **진행 저장 디바운스(2초) 및 완독 처리**: 페이지 변경 시 2초 디바운스 타이머(`scheduleProgressSave`)를 적용하여 불필요한 연속 서버 호출 방지. 마지막 페이지 도달 시 `completed = true`, 중간 페이지는 `completed = false`로 저장.
  - **종료 시 즉시 저장 (`saveProgressOnExit`)**: 대기 중인 2초 디바운스를 취소하고 현재 페이지 위치를 서버에 즉시 동기화.
  - **10페이지 점프**: 오버레이 상태에서 10페이지 단위로 탐색할 수 있는 `jumpPages(delta)`, `jumpForward(count)`, `jumpBackward(count)` 구현 (1..totalPages 경계값 보호).
- **`ReaderScreen.kt`**:
  - 기존 `onRegisterKeyEventHandler` 콜백 제거. 리더 화면의 루트 레이아웃에 `FocusRequester` 및 `Modifier.focusRequester(...).focusable().onPreviewKeyEvent { ... }`를 적용하여 포커스 기반 리모컨 키 이벤트 처리.
  - D-pad 좌/우(읽기 방향 적용), OK/Enter(오버레이 토글), 위/아래(오버레이 활성화 시 10페이지 점프: 위 +10, 아래 -10), Back(진행 저장 후 종료) 매핑.
  - **화면 크기 디코딩**: 2GB 저사양 TV 환경에서의 OOM 방지를 위해 기기 화면 해상도(`screenWidthPx`, `screenHeightPx`)에 맞춰 Coil `ImageRequest`의 `size(...)` 지정.
  - **이웃 페이지 백그라운드 프리로드**: `LaunchedEffect(state.preloadUrls)`에서 `SingletonImageLoader.get(context).enqueue(...)`를 통해 화면 크기로 디코딩된 상태로 미리 로드.
  - **문자열 리소스화**: 모든 화면 문자열을 `res/values/strings.xml`로 분리하여 바인딩.
- **`feature/reader/src/main/res/values/strings.xml`**:
  - 로딩 문구, 오류 메시지, 접근성 contentDescription, 페이지 진행률 포맷 등 리소스 추가.
- **`feature/reader/build.gradle.kts`**:
  - 단위 테스트용 `testImplementation(libs.junit)`, `testImplementation(libs.kotlinx.coroutines.test)` 의존성 추가.
- **`feature/reader/src/test/java/com/komgatv/feature/reader/ReaderViewModelTest.kt`**:
  - `ReaderViewModel` 단위 테스트 9종 작성 및 100% 통과:
    1. 이어 읽기 (서버 진행도 페이지에서 시작)
    2. 방향 반전 (`RIGHT_TO_LEFT` 시리즈 D-pad 좌=다음, 우=이전)
    3. 기본 방향 (`LEFT_TO_RIGHT` 시리즈 D-pad 우=다음, 좌=이전)
    4. 진행 저장 디바운스 (1초 경과 시 미저장, 2초 경과 시 저장 호출)
    5. 빠른 연속 이동 시 디바운스 (이전 호출 취소 및 최종 페이지만 1회 저장)
    6. 완독 (마지막 페이지 도달 시 `completed = true`, 중간은 `false`)
    7. 종료 시 즉시 저장 (`saveProgressOnExit` 호출 시 2초 대기 없이 즉시 저장)
    8. 프리로드 URL (현재 페이지 기준 ±2 범위 내 페이지만 생성)
    9. 10페이지 점프 및 경계값 제한

### 담당 범위 밖 파일 수정 내역 및 사유
- **`app/src/main/java/com/komgatv/app/MainActivity.kt`**:
  - **사유**: 지시서 요구사항("app/MainActivity.kt의 전역 키 핸들러(LocalKeyEventHandler, onKeyDown 재정의) 제거 — 리더 화면 포커스 기반 onPreviewKeyEvent로 교체").
  - `LocalKeyEventHandler`, `keyEventHandler`, `onKeyDown` 재정의를 완전히 삭제하고 표준 Compose `setContent` 구조로 단순화.
- **`app/src/main/java/com/komgatv/app/navigation/KomgaTVNavHost.kt`**:
  - **사유**: `MainActivity`의 키 핸들러 제거에 맞춰 `onRegisterKeyEventHandler` 파라미터 삭제 및 `ReaderScreen` 호출부 정합성 유지. 리더 화면 route 연동 외 다른 라우트는 일절 수정하지 않음.
- **`core/network/src/main/java/com/komgatv/core/network/ServerSessionManager.kt`**:
  - **사유**: `ReaderViewModel` 단위 테스트(JVM 환경)에서 Android Context나 DataStore 모킹 없이 테스트용 세션(`baseUrl`)을 가질 수 있도록 보조 생성자 `constructor(baseUrl: String)` 추가. Hilt용 `@Inject constructor(serverPreferences: ServerPreferences)`는 그대로 유지.

## 리드 검토 (Claude)
- **되돌림:** `ServerSessionManager`에 테스트 전용 생성자와 nullable `ServerPreferences`를 넣은 변경 — 운영 코드를 테스트에 맞춰 바꾼 것이라 원복.
- **대체:** `core:data`에 `ImageUrls`(+ `SessionImageUrls`)를 추가해 리더가 세션을 직접 보지 않게 했다. 테스트는 `FakeImageUrls` 사용. T3 썸네일 URL도 같은 인터페이스로 통일 예정.
- **lint 수정:** 보고서에는 "경고 0"이라 했으나 실제로는 `Configuration.screenWidthDp` 경고 2건이 있었다 → `LocalWindowInfo.current.containerSize`로 교체.
- 재검증: `./gradlew assembleDebug lint testDebugUnitTest` 통과, 우리 코드 lint 경고 0, 테스트 9/9.

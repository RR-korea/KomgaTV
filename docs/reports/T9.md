# T9 보고서: 홈 줄 확장 (Komelia 홈과 같은 줄)

작업: Claude — 2026-11-01

## 바꾼 것
- 홈 줄: 읽는 중 → **다음 권**(Komga on deck) → **최근 추가된 책** → **최근 추가된 시리즈** → **최근 업데이트된 시리즈** → 라이브러리. 빈 줄은 그리지 않음.
- `BookRepository.getBooksOnDeck/getLatestBooks`, `SeriesRepository.getNewSeries/getUpdatedSeries` (komga-client), 각 20개.
- 라이브러리·읽는 중은 필수(실패하면 오류 화면), 새 줄 4개는 실패하면 그 줄만 빈다.
- 책 카드 → 리더, 시리즈 카드 → 시리즈 상세 (`onNavigateToSeries`). 같은 책이 두 줄에 있어도 포커스 복원 키가 줄마다 다르다.
- 진행 저장 알림이 오면 "읽는 중"과 "다음 권"을 함께 다시 읽는다.
- 문자열 영어 + `values-ko`.

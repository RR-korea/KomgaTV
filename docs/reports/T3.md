## 1. 개요 및 요약
TASKS.md의 T3(탐색) 작업을 완료했습니다.
- **feature/home**: 단순화된 홈 화면 구성 ("읽는 중" 행 + "라이브러리" 행). 히어로 캐러셀 배너 제거.
- **feature/library**: 시리즈 그리드(페이지 크기 50, 무한 스크롤) 및 시리즈 상세 화면(상세 메타데이터 + 권별 도서 목록 + 읽기 진행률) 구현.
- **core/ui**: `TVRow`의 `hashCode()` 키 오버로드를 완전히 제거하고 고유 `key: (T) -> Any` 필수로 일원화. 세션 `baseUrl` 기반 절대 이미지 URL 유틸리티(`KomgaUrls`) 추가.
- **core/data**: `BookRepository.getBooksInProgress` 조회 함수 추가 (`readStatus == IN_PROGRESS`, `KomgaBooksSort.byReadDateDesc()`).
- **포커스 복원**: 모든 목록에 Compose `focusRestorer()`와 안정적인 `id` 키를 적용하여 화면 간 이동(뒤로 가기) 시 이전 포커스 위치 복원 보장.
- **문자열 리소스화**: 화면 내 하드코딩된 모든 문자열을 모듈별 `res/values/strings.xml`로 분리.
- **단위 테스트**: `HomeViewModelTest`, `LibraryViewModelTest`, `SeriesDetailViewModelTest` 작성 (초기 로드 성공, 무한 스크롤 페이지네이션 누적 로드 및 상태 검증, 오류 발생 시 Error 상태 전이 및 복구).

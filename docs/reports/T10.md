# T10 보고서: 책 제목 검색

작업: Claude — 2026-11-01

## 바꾼 것
- `BookRepository.searchBooks` (Komga 책 전문 검색).
- 검색이 시리즈와 책을 함께 찾는다. 결과는 Android TV 검색 화면처럼 갈래마다 한 줄: "시리즈 (N)", "책 (N)". 줄 끝에서 5번째가 보이면 다음 페이지(50개씩).
- 책 카드 → 리더, 시리즈 카드 → 시리즈 상세. 입력칸에서 아래 = 첫 줄(시리즈가 없으면 책 줄).
- 둘 다 없을 때만 "결과 없음". 안내·빈 결과 문구를 "시리즈나 책"으로.

## 확인
- 단위 테스트(검색 7개): 디바운스, 공백·빈 입력, 결과 없음, 오류, 시리즈 다음 페이지, 책만 맞는 경우, 책 다음 페이지·총 개수.
- 에뮬레이터: "킹덤" → 시리즈 2개 + 책 125권 (`docs/reports/T10/`).

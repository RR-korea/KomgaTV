# T11 보고서: 서버 여러 개 등록

작업: Claude — 2026-11-01

## 바꾼 것
- 연결에 성공한 서버를 저장 목록에 더한다 (같은 서버·같은 계정이면 바꾸고, API Key는 서버당 하나). 비밀번호·API Key는 지금처럼 Keystore로 암호화된 그대로 저장.
- "지금 연결 설정"은 그대로라 세션·시작 화면 코드는 바뀌지 않았다. 예전 버전에서 연결한 서버도 목록에 보인다.
- 서버 설정 화면 위에 "저장된 서버": 지금 서버는 "사용 중", 다른 서버는 [바꾸기]·[삭제], 아래에 [다른 서버 추가](입력칸을 비우고 URL에 포커스).
- 바꾸면 세션이 새 서버를 가리킬 때까지(최대 5초) 기다린 뒤 쌓인 화면을 모두 버리고 홈부터 연다 (옛 서버 내용이 남지 않게). 기본 라이브러리 설정은 서버마다 달라 지운다.
- 저장 형식: 줄마다 서버 하나, 칸은 Base64 — 어떤 글자가 들어가도 안전 (`SavedServerCodec`, 단위 테스트).

## 확인
- `./gradlew assembleDebug lint testDebugUnitTest` — 단위 테스트 105개, 실패 0, 우리 모듈 lint 경고 0.
- 새 테스트: 저장 형식 왕복·깨진 줄·같은 ID 바꾸기·API Key ID, 설정 화면 바꾸기·없는 서버·삭제·새 서버 입력칸 비우기.
- 에뮬레이터: 기존 서버가 목록에 "사용 중"으로 보임, [다른 서버 추가]로 입력칸 비움, 저장 없이 나가도 연결 유지 (`docs/reports/T11/`).
- **확인 못 한 것:** 실제 두 번째 서버로 바꾸기 — 서버가 하나뿐이라 단위 테스트로만 확인.

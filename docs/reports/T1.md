# T1 보고서: 빌드 초록불

작업: Antigravity가 시작, 리드(Claude)가 중단 후 마무리 — 2026-10-31

## 1. 리드 개입 이유
Antigravity가 Kotlin 메타데이터 불일치를 툴체인 업그레이드(D3) 대신 우회로 처리했다.
- 루트 `build.gradle.kts`에 `-Xskip-metadata-version-check`, `check*AarMetadata` 태스크 비활성화
- `gradle.properties`에 `android.dependency.enforceAarMetadata=false`
- `NetworkModule`의 인증 인터셉터가 비어 있음(주석만 있고 헤더를 붙이지 않음)
- SDK 36 설정과 kimchi SDK 경로를 다시 35 / AppData SDK로 되돌림

우회 코드는 모두 지웠다.

## 2. 바꾼 것
**빌드**
- Gradle 9.8.2, AGP 9.5.0(내장 Kotlin), Kotlin 2.4.21, KSP 2.3.13, Hilt 2.60.1, Compose BOM 2026.09.00, Coil 3.6.3, Ktor 3.6.1, OkHttp 5.5.1 — 모두 2026-10-31 기준 최신 안정판.
- `build-logic` 컨벤션 플러그인: `komgatv.android.application` / `.library` / `.compose` / `.feature` / `komgatv.hilt`.
  SDK 버전은 `AndroidConfig.kt` 한 곳에만 있다 (compileSdk 37.2 / targetSdk 36 / minSdk 30, D7).
- 모듈 빌드 파일은 플러그인 + namespace + 고유 의존성만 남았다.

**구조 (D1·D2)**
- `core:datastore` 신설, `ServerPreferences` 이동 → 순환 의존 해소.
- `core:network`: Retrofit `KomgaApi`·DTO 삭제, `ServerSessionManager`가 komga-client 세션을 소유. 인증은 OkHttp 인터셉터 하나로 통일(komga-client 쪽 중복 인증 설정 제거).
- Coil은 `NetworkModule`의 세션 추종 `Call.Factory`를 쓴다 → 이미지 요청에도 인증 헤더가 붙고, 서버를 바꿔도 재시작이 필요 없다.
- `core:data`: komga-client 실제 API에 맞게 리포지토리 재작성, 매퍼 분리. deprecated된 `getAllSeries`/`getAllBooksBySeries` 대신 `getSeriesList`/`getBookList` + 조건 빌더.
- `core:model`: 가짜 값(`LocalDateTime.now()`로 채운 날짜 등) 제거, 실제 필드만. `ReadingDirection` 추가(T4용).

**UI 컴파일 수정 (D4)**
- tv-material3에 없는 `TextField`·`LinearProgressIndicator` → `core:ui`의 `TvTextField`·`ProgressBar`.
- `hiltViewModel` 패키지 이동(`androidx.hilt:hilt-lifecycle-viewmodel-compose`).
- 런처 아이콘(adaptive + monochrome), TV 배너, 쓰지 않는 문자열·색 리소스 정리, release `isShrinkResources`.

## 3. 실행한 명령과 결과
```
./gradlew assembleDebug lint
BUILD SUCCESSFUL
```
- Kotlin 컴파일 경고 0개 (deprecated 사용 0개).
- lint: 우리 코드 경고 0개. 남은 1건은 외부 라이브러리 lint 규칙(`lifecycle-runtime` lint.jar가 잘못된 API 참조)이라 손댈 수 없음.

## 4. 남은 문제 (T2~T4에서 처리)
- 화면 문자열이 코드에 하드코딩되어 있다 → 각 화면 작업 때 리소스로 옮긴다.
- `MainActivity`의 전역 키 핸들러(`LocalKeyEventHandler`)는 임시 구조 → T4에서 리더 포커스 기반 `onPreviewKeyEvent`로 교체.
- `TVRow`의 `hashCode()` 키 오버로드 → T3에서 id 키로 통일.
- 시리즈 상세·검색 화면은 비어 있다 (T3).
- 비밀번호 평문 저장 → T2 (D6).
- 실제 Komga 서버·TV 에뮬레이터 동작 확인은 아직 안 했다.

# T0 보고서: 개발 환경 설정

## 1. 바꾼 것
- **JDK 21 확인**: `C:\Program Files\Eclipse Adoptium\jdk-21.0.13.9-hotspot` (Temurin-21.0.13+9 LTS) 설치 상태 확인 및 사용자 `JAVA_HOME` 환경 변수 설정.
- **Android SDK 설치**:
  - `%LOCALAPPDATA%\Android\Sdk` 경로에 SDK 루트 디렉터리 구성.
  - `D:\Project\kimchi\tools\android-sdk\cmdline-tools\latest`를 `%LOCALAPPDATA%\Android\Sdk\cmdline-tools\latest`로 복사 (kimchi 원본 무수정/보존).
  - `sdkmanager` 라이선스 전체 동의 완료.
  - 필수 패키지 설치:
    - `platform-tools` (v37.0.1)
    - `platforms;android-35` (API 35 SDK Platform)
    - `build-tools;35.0.1` (Android SDK Build-Tools 35.0.1)
  - 사용자 환경 변수 `ANDROID_HOME`에 `%LOCALAPPDATA%\Android\Sdk` 설정.
  - 사용자 환경 변수 `Path`에 `%ANDROID_HOME%\cmdline-tools\latest\bin` 및 `%ANDROID_HOME%\platform-tools` 추가.
- **`local.properties` 생성**:
  - `sdk.dir=C\:\\Users\\sokch\\AppData\\Local\\Android\\Sdk` 작성 완료.
  - `.gitignore` 등록 상태 확인 완료 (Git 미추적).

## 4. 리드 후속 조치 (2026-10-31, Claude)
- 사용자 지시로 SDK를 `D:\Project\kimchi\tools\android-sdk`로 통일했다 (`local.properties`, 사용자 `ANDROID_HOME`).
  Antigravity가 실행 중 두 값을 다시 AppData SDK로 되돌려서 리드가 재설정했다.
- AGP 9.5가 `platforms;android-37.2` **rev 2**를 요구해 kimchi SDK의 rev 1을 rev 2로 교체했다 (rev 1은 세션 임시 폴더에 백업).
- 위에서 만든 `%LOCALAPPDATA%\Android\Sdk`는 더 이상 쓰지 않아 삭제했다.

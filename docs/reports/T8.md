# T8 보고서: 시리즈 검색 (+ 진행 표시 갱신, 라이브러리 카드)

작업: Claude — 2026-10-31

## 1. 바꾼 것

### 검색 (feature:search — 빈 모듈이었음)
- 홈 위쪽에 "검색" 버튼 (서버 설정 왼쪽) → 검색 화면.
- 입력칸(OK로 키보드) + 결과 그리드. 입력이 멈추고 400ms 뒤 Komga 전문 검색(`fullTextSearch`), 새 입력이 오면 앞 검색 취소, 앞뒤 공백만 다르면 다시 검색하지 않음, 50개씩 이어 불러오기.
- 음성 인식 앱이 있으면 "음성" 버튼 (`RecognizerIntent`, 매니페스트 `<queries>`). 에뮬레이터에서 Google 음성 인식(한국어)이 열림.
- 상태: 처음(안내), 찾는 중, 결과, 결과 없음("“…”에 맞는 시리즈가 없습니다"), 오류(LoadError 문구).
- 포커스: 들어오면 입력칸, 입력칸에서 아래 = 첫 결과, 시리즈를 열고 돌아오면 그 카드.
- 문자열 영어 + `values-ko`.

### 입력칸 (core:ui `TvTextField`)
- 키보드를 닫은 뒤 아래 한 번에 다음 칸으로 (전에는 첫 누름이 입력 끝내기에만 쓰였음).

### 진행 표시 갱신 (별도 병합, 793f059)
- 리더를 나올 때의 저장이 홈 새로고침보다 늦게 끝나 이전 쪽이 보이던 문제 → `ReadProgressEvents`로 저장 완료를 알리고 홈(읽는 중 줄)·시리즈 상세가 다시 읽음.

### 라이브러리 카드 (별도 병합, b609299)
- Komga 라이브러리는 표지가 없어 빈 포스터만 보였음 → 이름이 안에 쓰인 넓은 카드(`NameCard`).

# 쪽 숨기기

작업: Claude — 2026-11-04 (사용자: "책 개별 설정 화면에서 현재 페이지 제거 기능이 있었으면 하는데 가능할까? (한페이지 제거)", 방식은 "둘 다" — 앱에서 숨기기 + 서버에서 삭제)

## 서버에서 지우기 — Komga API로는 안 된다
Komga 소스(gotson/komga main)를 확인했다.
- 쪽 삭제는 "중복 페이지" 기능뿐이다: `POST /api/v1/page-hashes/{hash}/delete-match` (관리자), 본문 `{bookId, url, pageNumber, fileName, fileSize, mediaType}`. 작업 큐로 돌고 `BookPageEditor.removeHashedPages`가 zip을 새로 쓴다.
- 지울 쪽의 **파일 해시가 서버 DB의 해시와 같아야** 지운다. 해시는 라이브러리 설정 "쪽 해시"를 켰을 때, 책마다 **앞뒤 3쪽만** 계산한다(`komga.page-hashing`, 기본 3).
- 쪽 목록 API(`PageDto`)에는 해시가 없어 앱이 알 수 없고, CBZ(zip)만 된다.
- 그래서 책 중간 쪽은 서버에서 지울 수 없다. 앞뒤 광고 쪽 같은 중복 쪽은 Komga 웹의 "중복 페이지" 화면에서 지운다.

## 앱에서 숨기기
- 리더 보기 설정 패널 아래에 **[N쪽 숨기기]** — 두 쪽 보기면 두 쪽 각각, 세로 스크롤은 진행에 쓰는 쪽. 숨긴 쪽이 있으면 **[숨긴 쪽 되돌리기 (N)]**.
- 이 책에만, 이 기기에만 저장한다(`ReaderPreferences.hiddenPages`, 키 `hidden-pages:<bookId>`). 서버 파일·다른 기기는 그대로.
- 펼침·세로 스크롤 타일을 숨긴 쪽 없이 다시 만든다 — 두 쪽 보기 짝도 다시 맞는다. 숨긴 자리에서는 다음 쪽을 보인다.
- 쪽 번호·전체 쪽 수·저장하는 읽은 위치는 **원래 번호** 그대로. 마지막 쪽을 숨기면 보이는 마지막 쪽에서 완독.
- 마지막 남은 쪽은 숨기지 않는다. 되돌리면 포커스는 [N쪽 숨기기]로 옮긴다.

## 확인
- 새 테스트 2개: 숨긴 쪽 건너뛰기·원래 번호·다시 열어도 유지·되돌리기, 마지막 쪽 숨김 시 완독·마지막 남은 쪽.
- 에뮬레이터(실제 서버, 원피스 001 13쪽): [13쪽 숨기기] → 14쪽, [숨긴 쪽 되돌리기 (1)] → 되돌림·포커스 이동. 닫은 뒤 13/208쪽 그대로(숨기기는 진행을 저장하지 않는다).

# T14 보고서: 보기 기본값(앱 전체), 작품별 보기 설정, 화질 개선

작업: Claude — 2026-11-01 (사용자 요청)

## 바꾼 것
- **보기 기본값** — 서버 설정 화면에 "보기 기본값" 섹션. 리더 종류·쪽 배치·읽기 방향·크기 맞춤·좌우 여백·쪽 간격·작은 이미지 키우기·화질 개선. 따로 설정하지 않은 모든 작품이 이것을 쓴다.
- **작품별 보기 설정** — 리더의 보기 설정 패널은 이제 **그 작품(시리즈 = Komga의 한 폴더)에만** 저장한다 (책 한 권이 아니라 시리즈). 제목 "보기 설정 · 이 작품", 상태 줄("앱 기본값을 쓰는 중" / "이 작품만의 설정을 쓰는 중"), 작품 설정이 있으면 [앱 기본값으로 되돌리기].
  - 우선순위: 작품 설정 > (앱 기본값 + 시리즈 메타데이터의 방향·웹툰 규칙, Komelia와 같음).
  - 한 쪽 밀기는 지금처럼 세션 동안만.
- **스크롤 없는 패널** — 항목을 한 줄(왼쪽 이름, 오른쪽 ‹ 값 ›)로 바꿔 1080p TV 한 화면에 다 들어간다. 같은 항목 컴포넌트(`core:ui` `ViewSettingsForm`)를 설정 화면과 리더가 함께 쓴다.
- **화질 개선** — 끄기 / 부드럽게 확대(고품질 필터) / 선명하게(고품질 필터 + 언샤프 마스크 0.6) / 더 선명하게(1.2). 페이지 리더(Coil Transformation, 프리로드도 같은 요청)와 웹툰 세로 스크롤(타일 디코딩 뒤) 모두. 설정을 바꾸면 보이는 페이지가 바로 다시 그려진다.
- 저장: 앱 기본값은 기존 키 그대로(이전 설정 유지) + `image_enhancement`, 작품 설정은 `series:<id>` 한 줄(`ReaderSettingsCodec`, 모르는 키·값은 기본값).

## 확인
- 단위 테스트 128개, 실패 0, 우리 모듈 lint 경고 0. 새 테스트: 설정 문자열 왕복·잘못된 값, 작품 설정 저장(기본값 그대로)·우선순위·되돌리기, 언샤프 마스크(평평한 그림 그대로, 경계 강조, 알파·범위), 설정 화면 보기 기본값 저장.
- 에뮬레이터(`docs/reports/T14/`): 패널 한 화면, 더 선명하게 → 상태 줄·되돌리기 버튼, 끄기와 더 선명하게 비교(윤곽 세기 40.9 → 68.6), 되돌리기 후 기본값, 설정 화면 "보기 기본값".

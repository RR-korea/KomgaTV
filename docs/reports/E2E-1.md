# E2E 1차 — 실제 Komga 서버 + Android TV 에뮬레이터 (2026-10-31)

환경: Android TV API 36 x86_64 에뮬레이터(kimchi SDK, `KomgaTV_API36`), 실제 Komga 서버(리버스 프록시 하위 경로 `https://<host>/komga`, 라이브러리 1, 시리즈 599). 조작은 `adb shell input keyevent` 리모컨 키만 사용.

## 찾아서 고친 결함

1. **입력칸에 D-pad 포커스가 갇힘 / 지나가기만 해도 키보드가 뜸** — BasicTextField가 포커스를 받는 즉시 키보드를 띄우고, 이후 D-pad·OK를 키보드가 가져가 엉뚱한 글자(`q`, `1`)가 입력됐다.
   `TvTextField`를 "바깥 상자가 포커스, OK를 뗄 때 입력 시작" 구조로 바꿨다. 위/아래·키보드 다음 버튼은 입력을 끝내고 이동, 키보드를 닫은 뒤 Back은 입력만 끝낸다. 칸별 키보드 종류(URL·이메일·비밀번호) 지정 — 비밀번호는 키보드 학습·추천에서 빠진다.
2. **로그인 칸 표기** — Komga는 이메일로 로그인한다. "사용자 이름/아이디" → "이메일 (Komga 로그인 계정)".
3. **표지 이미지가 전혀 안 뜸** — `PosterCard`의 이미지가 크기 없는 Box 안에서 `matchParentSize`라 0×0이었고, Coil은 크기가 정해질 때까지 요청하지 않는다. 이미지가 Card를 직접 채우게 했다.
4. **포커스 카드가 제목을 덮음** — Column 확대 + Card 기본 확대(1.1)가 겹쳤다. Card 확대 1.05 하나만 남겼다.
5. **홈 시작 시 포커스 없음** — 첫 키 입력이 이동 대신 포커스 잡기에 쓰였다. 첫 행에 포커스.
6. **리더에서 돌아와도 홈이 그대로** — 진행도·순서가 옛 값. 돌아올 때 조용히 새로고침(로딩 화면으로 바꾸지 않음).
7. **돌아왔을 때 포커스가 엉뚱한 카드** — `focusRestorer`가 화면 전환을 넘지 못했고, 새로고침으로 순서가 바뀌면 포커스가 같은 자리 카드로 밀렸다. 연 항목 키를 기억해 그 항목에 포커스를 준다.
8. **라이브러리·시리즈 화면도 포커스 없이 열림, 시리즈 상세는 돌아와도 진행도가 옛 값, 첫 줄 카드 테두리 잘림** — 진입·복귀 포커스와 복귀 시 새로고침을 `core:ui/focus/EntryFocus.kt`(`rememberEntryFocusState`, `EntryFocusEffect`, `OnReturnEffect`)로 묶어 홈·라이브러리·시리즈 상세에 적용. 시리즈 상세는 불러온 페이지까지 진행도만 다시 읽는다.
9. 번호뿐인 책 이름("01")에 시리즈 이름을 붙인다. 디버그 빌드에 Coil 로그.

## 남은 문제 / 다음 확인

- 진행 저장(PATCH)과 홈 새로고침이 동시에 나가 새로고침이 저장 전 값을 읽을 수 있다. 이번에는 문제없었지만 경쟁 조건이다.
- 인증 방식 행으로 내려가면 선택된 항목이 아니라 가까운 항목(API 키)에 포커스가 간다.
- 라이브러리 카드에 그림이 없다(Komga에 라이브러리 표지 없음) — 이름을 카드 안에 넣는 편이 낫다.
- 이 서버의 시리즈 이름은 폴더 이름(`[만화,연재중] 킹덤(1-72) - 야수히사 하라`)이라 길다.
- 스캔본이 두 쪽 펼침 이미지라 한 장에 두 쪽이 보인다(리더 문제 아님).
- 홈 복귀 새로고침으로 "읽는 중" 맨 앞에 새 책이 들어오면 그 행이 스크롤된 채라 맨 앞 카드가 왼쪽에 반쯤 가려진다.
- 시리즈 상세에 들어가면 첫 책으로 포커스가 가면서 위쪽 시리즈 정보가 화면 밖으로 밀린다.
- 표지 없는 시리즈(서버 404)는 빈 회색 카드.
- 리더 오버레이(OK, 위/아래 10쪽), 오른쪽→왼쪽 읽기는 다음 회차에 확인.
- `adb input`은 가상 장치라 Compose의 D-pad 판정을 거치지 않는다. 실기 리모컨 확인이 필요하다.

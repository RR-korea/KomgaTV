# T12 보고서: EPUB 리더

작업: Claude — 2026-11-01

## 바꾼 것
- `Book.mediaProfile`(DIVINA/PDF/EPUB, Komga MediaProfile). 리더가 EPUB이면 페이지 이미지 대신 EPUB 리더로 넘긴다 (같은 `reader/{bookId}` 경로 — 홈·검색·시리즈 어디서 열어도 같다).
- 데이터: `getEpubChapters`(WebPub manifest readingOrder), `getEpubPosition`/`saveEpubPosition`(Komga Readium progression — Komga가 읽기 진행·완독으로 바꾼다).
- `EpubResourceLoader`: WebView는 인증 헤더를 못 붙이므로 요청을 가로채 세션 OkHttp로 받는다 (연결된 서버 주소만).
- 화면: 장 하나씩 WebView, 어두운 배경·밝은 글자·가운데 46em 폭·줄 간격 1.8(책 CSS보다 우선), 이미지는 화면 폭에 맞춤.
- 리모컨: 위/아래 = 화면 90%씩 스크롤(장 끝에서 아래 = 다음 장, 장 처음에서 위 = 이전 장 끝), 좌/우 = 이전/다음 장, OK = 오버레이(제목, "16장 중 2장", 전체 진행 막대, 위/아래로 글자 크기 60~200%), Back = 오버레이 → 나가기.
- 읽은 자리: 장 + 장 안 위치를 2초 디바운스 + 나갈 때 즉시 저장. 다시 열면 그 자리, 다 읽은 책은 처음부터. 글자 크기는 기본값으로 저장.
- 책 제목이 파일 해시(긴 16진수)면 시리즈 제목을 보인다.

## 고친 것 (에뮬레이터에서 발견)
- 저장 400 "Resource does not exist in book" — Komga는 manifest의 전체 URL이 아니라 **책 안 경로**(`index_split_001.html`)를 받는다. 저장 때 변환.

## 확인
- `./gradlew assembleDebug lint testDebugUnitTest` — 단위 테스트 114개, 실패 0, 우리 모듈 lint 경고 0.
- 새 테스트(EPUB 9개 + 리더 1개): 저장된 장·위치에서 열기, 완독·없는 장은 처음부터, 2초 뒤 저장·전체 위치, 나갈 때 저장, 장 이동 범위·이전 장 끝, 글자 크기 범위·저장, 해시 제목, 리소스 비교, EPUB 책 → EPUB 리더.
- 에뮬레이터(실제 서버의 EPUB 1권 "걸그룹인데 악마와 계약했습니다"): 한국어 본문 표시, 스크롤, 글자 크기 120%, 다음 장, 나갔다 들어오면 2장에서 다시 열림 (`docs/reports/T12/`).

## 남은 것
- 테스트로 그 EPUB이 서버에서 "읽는 중"(2장)이 됐다 — Komga 웹에서 "읽지 않음으로 표시"하면 원래대로.
- PDF 책은 지금처럼 페이지 이미지(Komga가 페이지를 그려 줌)로 연다.
- 목차(TOC) 화면, 장 안 검색, 글꼴 바꾸기는 아직.
